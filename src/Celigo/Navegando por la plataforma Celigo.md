Integration tiles found on the homepage provide an overview about the integration.

The information that appears on a tile depends on how the integration is performing and your permissions.

﻿
Status
You'll see either a green dot with the word "Success" or a red dot with the number of errors for the last 30 days.
Connection Down
A broken link icon will appear if a connection within the integration is not working.
Permissions
If you have permissions, this icon will appear. Its appearance depends on what type of permissions you have (manage or monitor).

Permission icon as it appears in an integration tile for users who only have monitor permissions
You can switch from tile view to list view by selecting the list view option in the top-right corner. List view displays different information about an integration. For example, list view has a column showing what applications (endpoints) are used in a flow.

The homepage in list view
Dashboard
When you select Dashboard on the navigation menu, the platform shows a complete list of running flows in your workspace.

﻿
Each listing includes information such as what integration the flow is part of, its status, when it started, and errors. Under the Actions column, you can also choose to cancel its run.

﻿
Additionally, there's a search box , as well as options to filter flows by application, integration, flow, or status. The remaining columns, which don't include filters, can be sorted.

Dashboard filter and sorting options
All this information is part of the "Running flows" tab, which is the default view for Dashboard. You can switch to the "Completed flows" tab, which - as the name states - displays information for flows that already ran.

﻿
The column options in this view change to include last run, average run time, and open errors. In the Actions menu, you can choose to edit or run the flow.

Dashboard "Completed flows" tab

There's also the additional filtering option of a date range for flows listed in the "Completed flows" tab.
Note: If you have access to B2B Manager, a third tab named EDI activity will appear in the dashboard. The information in the EDI activity dashboard is covered in the B2B Manager course .

Navigating to Flow Builder

You'll create flows in Flows, which you can access from the home page in two ways.

﻿
Option 1: In the left navigation, Flows can be found in the Build menu.

﻿
Option 2: In the upper-right corner, select the Create menu and choose Flow.

﻿
You can walk through the second option in the activity below.

Resources Menu

We'll look at the navigation menus options, as you're introduced to each of the concepts.

﻿
One navigation menu displays flow components we've already covered. In the Resources menu, you'll find connections, imports, and exports.

﻿
As the previous lesson covered, these are standalone resource objects, which are independent from a flow. As such, you can find them separate from the Flow Builder.
